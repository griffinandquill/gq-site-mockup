Quillhaven Forge · spring 2027

Pick a topic. Pick a skill. An adult approves it.

Quillhaven Forge is a simulation maker for any subject. You choose a topic and a skill, and Forge drafts a simulation. Quests are one result it can make. An adult approves that result before a student uses it.

The first version is planned for spring 2027. One login and one subscription covers Forge, Quillhaven, and the Command Center. Forge is not for sale yet.

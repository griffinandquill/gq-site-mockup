Where we are going

Vision

One adventure where every academic skill is a chapter to master, every challenge ends with proof of learning, and every student carries those skills into every subject.

How we get there

Mission

Griffin & Quill teaches, grows and maintains students’ academic skills across all subjects through tutoring, the store, and Quillhaven, each built by a practicing teacher around one habit: learn it, then prove it.

Quillhaven, the company’s learning game, uses its own line: Write your own legend. Learn it. Live it. PROVE IT!

Founder

Ryan Mayer is a South Carolina licensed, ESOL-licensed teacher. He teaches U.S. History, Government, Economics, and AP Human Geography, previously taught in New York, and holds a Master’s in History Education, with more than seven years in the classroom.

He founded Griffin & Quill LLC.

Values

Open a value to see where it already shows up on this site.

Mastery over memorization

We build skills students can use on anything new, not facts they repeat once and forget.

Where you can see it: the sample on the home page asks you to use map evidence, not recall a fact. Try the sample

Practice, then prove it

Every lesson, session and run moves from guided practice to a clear demonstration of the skill.

Where you can see it: tutoring moves from a skills check to a written plan to sessions with one goal each. Plan a first session

Durable retention

Skills are revisited, reinforced and rewarded over time so they last beyond the unit or the test.

Where you can see it: each tutoring session ends with a note you can reread later. See tutoring

Play with purpose

Every game mechanic, reward and challenge exists to serve learning, never to distract from it.

Where you can see it: in Quillhaven, a student uses the skill to make choices in the story, then proves it on something new. The demo is planned. Read about Quillhaven

Teacher-built rigor

A practicing teacher designs every product to be demanding, accurate, original and trustworthy for families and co-ops.

Where you can see it: every store unit includes a DBQ and a unit test. Browse the shelf

Accessibility

Clear language, keyboard use, and readable type on this site. Quillhaven will need captions and a way to play without a mouse. We are building toward WCAG AA. The games are not built yet, so this is not a finished audit.

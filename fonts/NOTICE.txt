The Merriweather project OFL.txt on
https://github.com/EbenSorkin/Merriweather4 opens with a 2020 copyright
line for the same project URL and the same reserved name. The name
tables in these two WOFF2 files say 2024. fonts/OFL.txt uses the 2024
line from these files.

The Google Fonts METADATA for the Lato family currently uses a 2011-2015
copyright line. The name tables in these two Lato files say 2010-2011
and version 1.104, and each file contains 224 glyphs. This notice does
not describe them as that later full family.

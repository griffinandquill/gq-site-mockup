Quillhaven

Write your own legend.

Learn it. Live it. PROVE IT!

Quillhaven is gamified practice for academic skills. Students learn a skill, use it, and then prove they can carry it. The home-page chart is a sample story on this website. It is not the game, and it is not Quillhaven Forge.

A demo is planned for December 2, 2026. The current rebuild is TypeScript and Phaser 4. This page does not launch a game.

What practice means

Learn it

A skill is named in plain language: the idea a student needs in a real subject, not a costume for the idea.

Live it

The student uses that skill in a short activity. The activity is practice, not a claim that a finished game is open.

Prove it

The student shows the skill on something new. That check is the point of the legend line. It is not live in a game on this site yet.

Quillhaven Forge

Planned · MVP spring 2027

Forge is a simulation maker for any subject. An adult enters a topic and an academic skill. The maker uses fixed templates. An adult approves what a student will see before the student sees it.

Forge is not open. The branching chart on the home page is a fixed sample with prewritten choices. It does not build a simulation, and it does not send anything to a model.

Command Center

Planned · not live

Command Center is the progress hub for a teacher or a parent. It is where an adult would see how practice is going. It is not a product you can sign in to.

Quillhaven, Forge, and Command Center are planned as one ecosystem with one login later. This site does not offer that login and does not sell a subscription.

Accounts, when they exist

  • Adult accounts only.
  • A student would get a generated username with no personal information.
  • Written answers would stay in the adult account.
  • Those answers would not be sent to an AI.

None of that storage is on this website. This page does not collect student work.

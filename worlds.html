Quillhaven

Write your own legend.

Learn it. Live it. PROVE IT!

Quillhaven is a learning game for academic skills. A student learns one skill, uses it inside a short quest, and then proves it on something new.

Planned A demo is planned for December 2, 2026.

Join the demo waitlist Try the sample on the home page

How a quest works

Every quest follows the same three steps, so a student always knows what the skill is and when they have shown it.

  1. 1

    Learn it

    The quest names one academic skill in plain language: the real idea a student needs in a real subject.

  2. 2

    Live it

    The student uses that skill to make choices in a short story, and the story answers back.

  3. 3

    Prove it

    The student shows the skill again on something new. That check is the point of the legend.

Two tools for the adults

Quillhaven is planned alongside two tools for parents and teachers. Neither one is open yet.

Planned · MVP spring 2027

Quillhaven Forge

Build skill practice for any topic. An adult picks a topic and an academic skill, Forge fills a fixed template, and the adult approves what a student will see before the student sees it.

Planned

Command Center

See student progress in one place. A teacher or parent would check how practice is going across Quillhaven and Forge.

The three are planned as one system with one adult login later. This site does not offer that login or sell a subscription. The current game rebuild is TypeScript and Phaser 4.

Privacy, by design

How accounts are planned to work when they exist. None of this storage is on this website, and this site does not collect student work.

  • Adult accounts only.
  • Students get a system-made username with no personal information.
  • Written answers stay with the adult account and can be deleted.
  • Written answers are never sent to an AI.
